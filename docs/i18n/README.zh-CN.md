### 如果 bug 又回来了，你的测试能发现吗？

Bite 检查 AI 编程助手说的"已修复"是不是真的。
它会在你项目的一份副本里把每个修复撤掉，然后运行你的测试。免费，不需要密钥。

## 马上试试

免费、不需要密钥，也从不修改你的文件。你需要 Python 3.10 或更高版本，以及 git。把下面两行粘贴到
任意终端（PowerShell、cmd、Terminal）：

```
python -m pip install bite-check
python -m bite_check --free
```

如果不在项目文件夹里运行，Bite 会先在一个虚构的小项目上演示。要检查你自己的项目，输入第二行和一个空格，
把项目文件夹拖进窗口（这样会自动填入路径），然后按回车。

## 为什么需要它

AI 帮你修 bug 时，常常会说："已修复，我还加了一个测试。"如果你不看代码，就无法知道这是不是真的。

测试就像一个小机器人：它只检查一件事，出错时就会大喊。Bite 故意把旧 bug 放回去，看看有没有测试大喊。
这就像用真的烟去测试烟雾报警器，而不是只相信那个小绿灯。

如果有测试大喊，这个修复就是受保护的。如果所有测试都没反应，bug 可能悄悄回来而没人发现。
Bite 会指出这个修复，你就可以对你的 AI 说："加一个没有这个修复就会失败的测试。"

## 怎么看结果

- ✅ **noticed by**（被发现）后面跟着一个测试名：这个测试保护着该修复。
- ⚠️ **NO TEST NOTICED**（没有测试发现）：撤掉修复后，所有测试仍然通过。bug 可能回来而没人察觉。

每次运行都会生成一个报告页面 `bite_proof/report.html`，可以在浏览器中打开。
